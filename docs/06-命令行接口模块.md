# 命令行接口模块

## 模块概述

命令行接口（CLI）模块为浮栈工具提供基于HTTP的命令行友好接口，使用纯文本格式返回结果，支持终端、脚本和自动化工具直接访问。模块设计了简洁的输出格式，便于管道处理和数据提取。

---

## 功能列表

### 1. CLI主入口

#### 1.1 CLI帮助信息

**功能描述：**
显示CLI接口的使用帮助信息，指导用户如何使用搜索和目录列表功能。

**接口：** `GET /api/v1/cli` 或 `GET /cli`
**认证要求：** 无需认证
**响应类型：** `text/plain`

**请求示例：**
```bash
# 直接访问（无需认证）
curl http://localhost:8080/api/v1/cli

# 浏览器访问
http://localhost:8080/cli
```

**响应数据：**
```
------------------------------------------------------------------------
浮栈 - CLI 帮助 (通过浏览器访问 http://localhost:8080 体验更佳)
------------------------------------------------------------------------

使用方法:
  http://localhost:8080/cli/search/  搜索文件，访问此地址查看检索帮助信息
  http://localhost:8080/cli/list/     浏览目录
```

**特性：**
- 自动重定向：访问`/cli`自动重定向到`/cli/`
- 纯文本格式：便于命令行工具解析
- 基础URL推断：自动检测HTTP/HTTPS协议

### 2. CLI文件搜索

#### 2.1 搜索文件（命令行格式）

**功能描述：**
在所有配置的根目录中搜索匹配的文件，以纯文本格式返回结果列表。

**接口：** `GET /api/v1/cli/search/*query` 或 `GET /cli/search/*query`
**认证要求：** 无需认证
**响应类型：** `text/event-stream`（流式传输）
**输出格式：** 纯文本，每行一个文件URL

**URL参数：**
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| query | string | 是 | 搜索关键词（URL路径的一部分） |

**请求示例：**

```bash
# 基础搜索
curl http://localhost:8080/api/v1/cli/search/document

# 按扩展名搜索
curl http://localhost:8080/api/v1/cli/search/document.pdf

# URL编码的中文搜索
curl http://localhost:8080/api/v1/cli/search/%E6%96%87%E6%A1%A3
```

**响应格式：**
```
------------------------------------------------------------------------
浮栈 - CLI 检索 (通过浏览器访问 http://localhost:8080 体验更佳)
------------------------------------------------------------------------

正在检索...

http://localhost:8080/download/files/annual_report.pdf
http://localhost:8080/download/files/project_document.docx
http://localhost:8080/download/files/class_document.pdf

搜索完成，共找到 3 个结果
```

**自动重定向：**
访问`/cli/search`自动重定向到`/cli/search/`

#### 2.2 空搜索关键字帮助

**请求示例：**
```bash
curl http://localhost:8080/api/v1/cli/search/
```

**响应数据：**
```
------------------------------------------------------------------------
浮栈 - CLI 检索 (通过浏览器访问 http://localhost:8080 体验更佳)
------------------------------------------------------------------------

错误：搜索关键字不能为空

使用方法:
    http://localhost:8080/cli/search/<关键字>      搜索文件
示例:
    http://localhost:8080/cli/search/document      搜索文件名包含'document'的文件
    http://localhost:8080/cli/search/document.exe  搜索文件名包含 document，扩展名为 exe 的文件
```

#### 2.3 搜索技巧

**文件名搜索：**
```bash
# 搜索包含"report"的文件
/cli/search/report

# 匹配：report.pdf, annual_report.docx, reports/
```

**多关键词搜索（AND 逻辑）：**
```bash
# 搜索同时包含"report"和"2024"的文件
/cli/search/report,2024

# 匹配：report_2024.pdf, 2024_annual_report.docx
# 不匹配：report_2023.pdf
```

**扩展名过滤：**
```bash
# 搜索PDF格式的报告
/cli/search/report.pdf

# 匹配：quarterly_report.pdf, report2024.pdf
# 不匹配：report.docx

# 搜索所有PDF文件
/cli/search/.pdf

# 匹配：document.pdf, report.pdf, image.pdf
```

**组合使用：**
```bash
# 搜索包含"report"且扩展名为 pdf 的文件
/cli/search/report,.pdf

# 匹配：annual_report.pdf, report_2024.pdf
# 不匹配：report.docx, summary.pdf
```

**支持的场景：**
- 脚本自动化：`curl /cli/search/query | grep pattern`
- 定时任务：查找特定文件并批量处理
- 日志分析：定期搜索并记录结果

## 技术实现

### 流式搜索

**技术特点：**
- 使用SSE（Server-Sent Events）实时推送结果
- 边搜索边返回，无需等待全部完成
- 每找到一个立即输出

**实现代码：**
```go
w.Header().Set("Content-Type", "text/event-stream; charset=utf-8")
w.Header().Set("Cache-Control", "no-cache")
w.Header().Set("Connection", "keep-alive")
w.Header().Set("Content-Encoding", "identity")  // 禁用压缩

// 使用Flusher实时推送
flusher := w.(http.Flusher)
for item := range resultChan {
    fmt.Fprintf(w, "%s\n", fullUrl)
    flusher.Flush()  // 立即发送
}
```

**客户端断开处理：**
```go
// 监听客户端断开连接
notify := w.(http.CloseNotifier).CloseNotify()
go func() {
    <-notify
    cancel()  // 取消所有搜索goroutine
}()

// 搜索中检查context
select {
case <-ctx.Done():
    return  // 提前退出
case resultChan <- item:
}
```

### 结果限制

**保护机制：**
- 最多返回1000条结果
- 超限后自动停止搜索

**实现代码：**
```go
totalCount++
if totalCount > 1000 {
    cancel()  // 取消搜索
    fmt.Fprintf(w, "\n检索结果超过 1000，中止检索\n")
    flusher.Flush()
    return
}
```

### 并发搜索

**多goroutine架构：**
```go
var wg sync.WaitGroup
resultChan := make(chan FileInfo)

// 为每个根目录启动搜索
for _, rootDir := range config.RootDirs {
    wg.Add(1)
    go func(ctx, dir, query, rootName) {
        defer wg.Done()
        // 搜索并推送到结果通道
        searchInDirectory(ctx, dir, query, rootName, resultChan)
    }(ctx, rootDir.Path, query, rootName)
}

// 等待所有搜索完成
go func() {
    wg.Wait()
    close(resultChan)
}()
```

**优势：**
- 多个目录同时搜索，提升速度
- 结果按找到顺序实时推送

### Python脚本示例

```python
import requests
import urllib.parse

BASE_URL = "http://localhost:8080/api/v1"

# 搜索文件
def search_files(query):
    url = f"{BASE_URL}/cli/search/{urllib.parse.quote(query)}"
    response = requests.get(url, stream=True)
    results = []
    for line in response.iter_lines():
        if line:
            results.append(line.decode('utf-8'))
    return results

# 列出目录
def list_directory(path=""):
    url = f"{BASE_URL}/cli/list/{path}"
    response = requests.get(url)
    return response.text

# 使用示例
files = search_files("report")
for file_url in files:
    if file_url.startswith("http"):
        print(f"找到文件: {file_url}")
```

## URL编码处理

### 必须编码的字符

**特殊字符：**
- 空格 → `%20`
- `/` → `%2F`（在路径部分）
- `?` → `%3F`
- `#` → `%23`
- `&` → `%26`
- `=` → `%3D`
- 中文 → UTF-8 URL编码

**示例：**
```
原始关键词: 2024年报告
编码后: 2024%E5%B9%B4%E6%8A%A5%E5%91%8A

请求URL: /cli/search/2024%E5%B9%B4%E6%8A%A5%E5%91%8A
```

### 编码工具

**bash:**
```bash
# URL编码
query="2024年报告"
encoded=$(printf '%s' "$query" | jq -sRr @uri)
echo $encoded

# 使用curl自动编码
curl "http://localhost:8080/api/v1/cli/search/$query" --data-urlencode ""
```

**Python:**
```python
import urllib.parse
query = "2024年报告"
encoded = urllib.parse.quote(query)
print(encoded)
```

CLI接口无需认证，可以公开访问：
```bash

```

**注意**：临时文件管理模块的接口需要认证，但这些接口不属于CLI模块的范畴。

### 路径安全

**防护措施：**
1. 路径格式验证（根目录名/子路径）
2. 根目录白名单检查
3. 符号链接限制
4. 路径越权检测

应用全局速率限制中间件（默认每分钟60个请求）

## 错误处理

| HTTP状态码 | 错误信息 | 原因 |
|-----------|---------|------|
| 200 | 正常返回 | 请求成功 |
| 400 | 路径格式不正确 | 路径不符合规范 |
| 400 | 指定的根目录名不存在 | 根目录未配置 |
| 400 | 指定路径不存在或非目录 | 目标路径问题 |
| 403 | 路径越权 | 试图越权访问 |
| 401 | 认证失败 | 缺少或无效令牌 |

## 服务管理命令

浮栈支持将程序安装为系统服务，实现开机自启和后台运行。

### 命令行参数

| 参数 | 说明 |
|------|------|
| `--install` | 安装服务 |
| `--uninstall` | 卸载服务 |
| `--status` | 查看服务状态 |
| `--name <name>` | 指定服务名称（默认 fuzhan） |
| `--user <user>` | 指定运行用户（Linux/macOS） |
| `-c <path>` | 指定配置文件路径 |

### 使用示例

**安装服务：**
```bash
# 安装服务（使用默认名称）
fuzhan --install

# 指定名称安装
fuzhan --install --name myservice

# 指定配置和用户
fuzhan --install -c /etc/fuzhan/fuzhan.yaml --user nobody
```

**查看状态：**
```bash
# 查看默认服务状态
fuzhan --status

# 查看指定服务状态
fuzhan --status --name myservice
```

**卸载服务：**
```bash
# 卸载服务
fuzhan --uninstall

# 卸载指定服务
fuzhan --uninstall --name myservice
```

### 平台实现

| 平台 | 实现方式 | 权限要求 | 服务文件位置 |
|------|----------|----------|-------------|
| Windows | sc.exe | 管理员 | Windows 服务管理器 |
| Linux | systemd | sudo | /etc/systemd/system/ |
| macOS | launchd | sudo | /Library/LaunchDaemons/ |

### Windows 示例

```powershell
# 以管理员身份运行
.\fuzhan.exe --install

# 查看服务状态
.\fuzhan.exe --status

# 卸载服务
.\fuzhan.exe --uninstall
```

### Linux 示例

```bash
# 安装服务
sudo ./fuzhan --install

# 指定运行用户
sudo ./fuzhan --install --user nobody

# 查看状态
sudo systemctl status fuzhan

# 查看日志
sudo journalctl -u fuzhan -f

# 卸载服务
sudo ./fuzhan --uninstall
```

### macOS 示例

```bash
# 安装服务
sudo ./fuzhan --install

# 查看状态
sudo launchctl list | grep fuzhan

# 卸载服务
sudo ./fuzhan --uninstall
```
