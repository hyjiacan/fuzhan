# 系统配置与选项模块

## 模块概述

系统配置与选项模块是整个应用的基础设施核心，负责配置管理、应用初始化、日志记录、资源加载等关键功能。该模块提供了灵活的配置机制，支持YAML配置文件、自动配置生成、配置热加载等特性，并提供了系统选项API供前端获取运行时配置。

## 功能列表

### 1. 配置文件管理

#### 1.0 命令行参数

应用支持以下命令行参数：

| 参数 | 简写 | 说明 | 默认值 |
|------|------|------|--------|
| --config | -c | 指定配置文件路径 | ./fuzhan.yaml |
| --create-admin | - | 创建管理员用户，格式: username:password | - |

**使用示例:**

```bash
# 使用默认配置
./fuzhan

# 使用自定义配置
./fuzhan -c /etc/fuzhan/config.yaml
./fuzhan --config ./custom-config.yaml

# 创建管理员
./fuzhan --create-admin admin:password
```

**优先级说明:**
- 命令行参数 `-c` 指定的路径优先于默认路径
- 配置文件不存在时，应用退出并显示错误信息

#### 1.1 配置文件结构

**配置文件路径：** `fuzhan.yaml`（可通过 `-c` 参数指定）

**配置结构：**

```yaml
# 应用配置
app:
  name: "轻共享"  # 应用名称（可选，默认为"轻共享"）

# 服务器配置
server:
  host: 127.0.0.1  # 监听地址
  port: 80         # 监听端口

# 存储配置
storage:
  # 公开共享目录配置
  public:
    root_dirs:
      - path: /path/to/share
        quota: 1G  # 1GB
      - path: /path/to/share2

  # 允许的文件扩展名（可选，留空表示允许所有）
  allowed_extensions:
    - txt
    - pdf
    - png
    - jpg
    - jpeg
    - gif

  # 临时文件配置
  temp:
    enabled: false  # 是否启用临时文件功能
    path: /path/to/temp  # 临时文件存储路径
    # 临时文件配额配置
    quota:
      global: 10G  # 全局临时文件配额（0表示无限制）
      per_ip: 1G   # 每IP临时文件配额（0表示无限制）

# 上传配置
upload:
  # 分片大小（支持单位: B, K, M, G, T）
  chunk_size: 10M  # 10MB（默认值）
  # 最大文件大小限制（0表示无限制，支持单位: B, K, M, G, T）
  max_file_size: 1G  # 1GB
```

**配置说明：**

| 配置项 | 类型 | 必填 | 描述 |
|--------|------|------|------|
| app.name | string | 否 | 应用名称，默认"轻共享" |
| server.host | string | 是 | 服务器监听地址 |
| server.port | int | 是 | 服务器监听端口 |
| database.driver | string | 否 | 数据库驱动：空/SQLite、mysql、postgres |
| database.dsn | string | 否 | 数据库连接字符串 |
| storage.public.root_dirs[] | array | 是 | 共享根目录配置 |
| storage.allowed_extensions[] | array | 否 | 允许的文件扩展名列表 |
| storage.temp.enabled | bool | 否 | 是否启用临时文件功能 |
| storage.temp.path | string | 否 | 临时文件存储路径（启用时必填） |
| storage.temp.quota.global | string | 否 | 全局临时文件配额 |
| storage.temp.quota.per_ip | string | 否 | 每IP临时文件配额 |
| upload.chunk_size | string | 否 | 分片上传大小 |
| upload.max_file_size | string | 否 | 最大文件大小限制 |

#### 1.2 数据库配置

**支持的数据库类型：**

| 类型 | 驱动值 | 适用场景 |
|------|--------|----------|
| SQLite | 空 或 `sqlite` | 轻量级，文件存储，适合小型部署或单机使用 |
| MySQL | `mysql` | 适合大规模应用，需要额外安装 MySQL 服务 |
| PostgreSQL | `postgres` | 功能丰富，适合企业级应用 |

**DSN 连接字符串格式：**

**SQLite：**
```yaml
database:
  dsn: "./fuzhan.db"  # 数据库文件路径
```

**MySQL：**
```yaml
database:
  driver: mysql
  dsn: "user:password@tcp(host:port)/database?charset=utf8mb4&parseTime=True&loc=Local"
```

**PostgreSQL：**
```yaml
database:
  driver: postgres
  dsn: "host=host port=port user=user password=password dbname=database sslmode=disable"
```

**配置示例：**

```yaml
# SQLite（默认）
database:
  dsn: "./fuzhan.db"

# MySQL
database:
  driver: mysql
  dsn: "root:password@tcp(localhost:3306)/fuzhan?charset=utf8mb4&parseTime=True&loc=Local"

# PostgreSQL
database:
  driver: postgres
  dsn: "host=localhost port=5432 user=postgres password=secret dbname=fuzhan sslmode=disable"
```

**注意事项：**
- MySQL 需要 5.7+ 版本，首次使用需手动创建数据库
- PostgreSQL 需要 10+ 版本，首次使用需手动创建数据库
- 程序会自动创建表结构（使用 GORM AutoMigrate）
- 生产环境建议为数据库用户设置合理的权限

#### 1.4 嵌入式默认配置

**功能描述：**
默认配置文件 `fuzhan.yaml` 作为嵌入资源打包到二进制文件中，首次启动时如不存在配置文件则自动释放到工作目录。

**实现方式：**
```go
//go:embed web/index.html web/assets web/icons fuzhan.yaml
var webAssets embed.FS
```

**触发条件：**
- `fuzhan.yaml` 文件不存在于工作目录

**特性：**
- 默认配置作为嵌入资源，无需额外文件即可运行
- 用户可编辑释放后的配置文件进行定制
- 支持 MySQL、PostgreSQL 数据库配置（默认使用 SQLite）

#### 1.5 配置文件解析

**功能描述：**
读取并解析YAML格式的配置文件，支持字符串格式的配额值自动转换为字节数。

**解析流程：**
1. 读取 `fuzhan.yaml` 文件
2. 使用YAML解析器解析配置内容
3. 转换字符串格式配额为数字配额
4. 验证配置有效性
5. 存储到全局配置对象

**配额字符串解析：**

支持的单位：
- `B`, `KB`: 字节
- `K`, `KB`: 千字节
- `M`, `MB`: 兆字节
- `G`, `GB`: 吉字节
- `T`, `TB`: 太字节

解析示例：
- `10M` → `10485760` (10 * 1024 * 1024)
- `1.5G` → `1610612736` (1.5 * 1024 * 1024 * 1024)
- `500K` → `512000` (500 * 1024)

**代码实现：**
```go
func ParseQuotaString(quotaStr string) (int64, error) {
    if quotaStr == "" {
        return 0, nil
    }

    quotaStr = strings.ToUpper(strings.TrimSpace(quotaStr))

    units := map[string]int64{
        "B":  1,
        "K":  1024,
        "KB": 1024,
        "M":  1024 * 1024,
        "MB": 1024 * 1024,
        "G":  1024 * 1024 * 1024,
        "GB": 1024 * 1024 * 1024,
        "T":  1024 * 1024 * 1024 * 1024,
        "TB": 1024 * 1024 * 1024 * 1024,
    }

    // 从字符串末尾开始查找单位
    for i := len(quotaStr) - 1; i >= 0; i-- {
        char := quotaStr[i]
        if char >= '0' && char <= '9' || char == '.' {
            numberStr = quotaStr[:i+1]
            unitStr = quotaStr[i+1:]
            break
        }
    }

    number, err := parseFloat(numberStr)
    multiplier := int64(1)
    if unitStr != "" {
        multiplier = units[unitStr]
    }

    return int64(number * float64(multiplier)), nil
}
```

### 2. 系统选项API

#### 2.1 获取系统选项

**功能描述：**
向客户端返回当前运行时配置选项。该接口无需认证，前端在加载时即可调用。

**接口：**
- **路径：** `GET /api/v1/options`
- **认证要求：** 无需认证
- **请求体：** 无

**响应数据：**
```json
{
  "success": true,
  "code": 0,
  "message": "",
  "data": {
    "app": {
      "name": "轻共享"
    },
    "temp": {
      "enabled": true
    },
    "tempFilesEnabled": true,
    "chunkSize": 10485760,
    "maxFileSize": 17179869184,
    "preview": {
      "textExtensions": ["txt", "md", "log", "json", "xml", "csv", "html", "css", "js", "ts", "vue", "yml", "yaml", "properties", "conf", "config", "sh", "bat", "ps1", "py", "java", "go", "rs", "c", "cpp", "h", "hpp", "sql", "ini", "toml"],
      "imageExtensions": ["png", "jpg", "jpeg", "gif", "bmp", "webp", "svg", "ico"],
      "otherExtensions": ["pdf"]
    }
  }
}
```

**字段说明：**
- `success`: 请求是否成功
- `code`: 错误码，0表示成功
- `message`: 消息描述
- `data.app.name`: 应用名称
- `data.temp.enabled`: 私有存储功能是否启用
- `data.tempFilesEnabled`: 临时文件功能是否启用
- `data.chunkSize`: 分片上传大小（字节），默认10MB
- `data.maxFileSize`: 最大文件大小限制（字节），0表示无限制
- `data.preview.textExtensions`: 支持预览的文本文件扩展名
- `data.preview.imageExtensions`: 支持预览的图片文件扩展名
- `data.preview.otherExtensions`: 其他支持预览的文件扩展名

**默认值处理：**
- 如果配置中未指定 `chunk_size`，使用默认值 10MB
- 如果配置中未指定 `max_file_size`，返回 0（无限制）
- 如果配置中未指定 `preview.textExtensions`，使用内置默认值

**应用场景：**
- 前端在上传前检查分片大小限制
- 前端检查临时文件功能是否可用
- 客户端根据配置调整上传策略
- 前端加载时获取预览配置（无需登录）

### 3. 应用初始化

#### 3.1 初始化流程

**初始化步骤：**

1. **获取工作目录**
   - 获取当前工作目录
   - 转换为绝对路径

2. **初始化日志系统**
   - 创建日志目录 `logs`
   - 创建日志文件 `app.log`
   - 配置日志输出（同时输出到文件和标准输出）

3. **创建配置文件**
   - 检查配置文件是否存在
   - 如不存在则自动生成默认配置

4. **读取配置**
   - 解析配置文件
   - 转换配额格式
   - 验证配置有效性

5. **初始化应用名称**
   - 读取 `index.html` 模板
   - 替换应用名称占位符 `{APP_NAME}`

6. **初始化根目录映射**
   - 验证根目录存在性
   - 创建目录名称到路径的映射
   - 检查重复目录名称

7. **初始化临时文件目录**
   - 创建临时文件根目录
   - 创建必要的子目录：
     - `files/`: 存储完整文件
     - `users/`: 用户目录
     - `metadata/`: 元数据目录

8. **完成初始化**
   - 记录初始化完成日志
   - 返回配置对象

**流程图：**
```
启动应用
  ↓
获取工作目录
  ↓
初始化日志系统
  ↓
配置文件存在？
  ├── 否 → 生成默认配置
  ↓
解析配置文件
  ↓
初始化应用名称（替换HTML模板）
  ↓
验证根目录配置
  ↓
创建根目录映射
  ↓
启用临时文件？
  ├── 是 → 创建临时文件目录结构
  ↓
初始化完成
  ↓
启动HTTP服务器
```

#### 3.2 配置验证

**根目录验证：**
- 检查配置的根目录数量（至少1个）
- 检查根目录是否存在
- 检查根目录名称是否重复

**临时文件目录验证：**
- 只有启用时才验证
- 检查是否配置了路径
- 尝试创建目录

**错误处理：**
| 错误情况 | 处理方式 |
|---------|---------|
| 根目录配置为空 | 应用退出，显示错误 |
| 根目录不存在 | 应用退出，显示错误 |
| 重复的根目录名称 | 应用退出，显示错误 |
| 创建临时文件目录失败 | 应用退出，显示错误 |

### 5. 资源管理

#### 5.1 嵌入资源系统

**功能描述：**
使用Go的 `embed` 功能将静态资源嵌入到二进制文件中，支持单文件部署。

**嵌入的资源：**
```go
//go:embed assets/*
var assets embed.FS
```

**资源优先级：**
1. 本地文件（`assets/` 目录）
2. 嵌入资源（编译到二进制中）

**资源获取：**
```go
func GetAssetContent(relativePath string) ([]byte, error) {
    // 优先从本地读取
    localPath := filepath.Join(WorkDir, "assets/"+relativePath)
    if _, err := os.Stat(localPath); err == nil {
        return os.ReadFile(localPath)
    }

    // 从嵌入资源中读取
    return EmbedAssets.ReadFile("assets/" + relativePath)
}
```

**优势：**
- 支持单文件部署
- 开发时可以修改本地资源
- 生产环境使用嵌入资源

#### 5.2 静态资源服务

**路由配置：**
```go
r.StaticFS("/assets", http.FS(assets))
```

**可访问的静态资源：**
- `/assets/*`: 静态文件服务
- `/favicon.ico`: 网站（返回404）

#### 5.3 HTML模板处理

**模板替换：**
```go
func initAppName(appInfo APPConfig) {
    data, err := GetAssetContent("index.html")
    appName := "轻共享"
    if name := appInfo.Name; name != "" {
        appName = name
    }
    UserHtmlTemplate = strings.ReplaceAll(string(data), "{APP_NAME}", appName)
}
```

**占位符：** `{APP_NAME}`
- 替换为配置中的应用名称
- 默认为 "轻共享"

### 6. 端口检测

#### 6.1 端口占用检查

**功能描述：**
在启动服务器前检查指定端口是否已被占用。

**接口：**
```go
func IsPortInUse(port int) bool
```

**实现方式：**
```go
addr := fmt.Sprintf(":%d", port)
listener, err := net.Listen("tcp", addr)
if err != nil {
    return true  // 端口被占用
}
defer listener.Close()
return false  // 端口可用
```

**错误处理：**
如果端口被占用，应用退出并显示错误：
```
启动失败：端口 80 已被占用
```

## 配置最佳实践

### 1. 端口配置

**建议：**
- 开发环境：使用 8080 或其他非特权端口
- 生产环境：使用 80 或 443（需要root权限或反向代理）
- 测试环境：使用随机端口

**示例：**
```yaml
server:
  host: 0.0.0.0  # 监听所有网卡
  port: 8080
```

### 2. 存储配置

**建议：**
- 使用绝对路径
- 确保权限正确
- 定期检查磁盘空间
- 配置合理的配额

**示例：**
```yaml
storage:
  public:
    root_dirs:
      - path: /data/documents
        quota: 50G
      - path: /data/images
        quota: 100G
      - path: /data/temp
        quota: 0  # 无限制

  # 允许的文件扩展名
  allowed_extensions:
    - .pdf
    - .doc
    - .docx
    - .txt
    - .jpg
    - .png
    - .gif
    - .zip

  # 临时文件配置
  temp:
    enabled: true
    path: /data/tempfiles
    quota:
      global: 100G   # 全局100GB
      per_ip: 5G     # 每IP 5GB
```

### 5. 上传配置

**建议：**
- 分片大小根据网络状况调整
- 设置合理的文件大小限制
- 考虑服务器性能

**示例：**

## 错误处理

### 配置错误

| 错误类型 | 描述 | 处理方式 |
|---------|------|---------|
| 配置文件不存在 | fuzhan.yaml 文件不存在 | 自动生成默认配置 |
| 配置文件解析失败 | YAML格式错误 | 应用退出，显示错误 |
| 根目录配置为空 | 没有配置根目录 | 应用退出，显示错误 |
| 根目录不存在 | 配置的根目录不存在 | 应用退出，显示错误 |
| 重复根目录名称 | 多个根目录同名 | 应用退出，显示错误 |
| 配额格式错误 | 配额字符串无法解析 | 应用退出，显示错误 |

### 运行时错误

| 错误类型 | 描述 | 处理方式 |
|---------|------|---------|
| 端口被占用 | 指定端口已被占用 | 应用退出，显示错误 |
| 日志文件创建失败 | 无法创建日志目录/文件 | 应用退出，显示错误 |
| 临时文件目录创建失败 | 无法创建临时文件目录 | 应用退出，显示错误 |
| 资源文件缺失 | index.html 等资源不存在 | 应用退出，显示错误 |

## 注意事项

1. **配置文件位置：**
   - 配置文件必须位于工作目录下
   - 首次运行会自动生成
   - 修改配置后需要重启应用

2. **配额格式：**
   - 必须使用有效的单位
   - 支持小数值（如 1.5G）
   - 0 表示无限制

3. **路径配置：**
   - 建议使用绝对路径
   - 目录必须存在
   - 确保正确权限

4. **日志文件：**
   - 日志位置固定
   - 文件会持续增长
   - 需要定期清理

5. **端口配置：**
   - 端口低于1024需要root权限
   - 端口被占用会导致启动失败
   - 建议使用反向代理
