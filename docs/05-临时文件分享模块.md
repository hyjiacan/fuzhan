# 临时文件分享模块

## 模块概述

临时文件分享模块提供具有过期机制的文件分享功能，支持基于客户端IP的配额控制、分片上传、访问码分享。

**认证策略：**
- **基于客户端IP** - 无需登录，按IP进行配额控制
- 同一IP可上传多个临时文件
- 分享链接通过8位访问码访问，下载无需认证

**与私有存储的区别：**
- 临时文件：基于IP，无需登录，适合短期分享
- 私有存储：需要JWT认证，用户私有文件

## 功能列表

### 1. 客户端IP识别

#### 1.1 获取客户端IP

**功能描述：**
获取当前客户端的IP地址，用于配额控制和文件归属。

**接口：**
- **路径：** `GET /api/v1/temp/client-ip`
- **认证要求：** 无需认证

**响应数据：**
```json
{
  "success": true,
  "data": {
    "ip": "192.168.1.100"
  }
}
```

---

### 2. IP配额查询

#### 2.1 查询IP配额

**功能描述：**
查询当前IP的临时文件配额使用情况。

**接口：**
- **路径：** `GET /api/v1/temp/quota`
- **认证要求：** 无需认证（基于IP）

**响应数据：**
```json
{
  "success": true,
  "data": {
    "maxFiles": 10,
    "usedFiles": 3,
    "maxSize": 104857600,
    "usedSize": 52428800,
    "expireTime": "2026-01-29T10:00:00Z"
  }
}
```

---

### 3. 临时文件上传

#### 3.1 简单上传

**功能描述：**
上传本地文件到临时存储，基于客户端IP控制配额。

**接口：**
- **路径：** `POST /api/v1/temp/upload`
- **认证要求：** 基于IP
- **请求格式：** `multipart/form-data`

**请求参数：**
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| file | file | 是 | 文件内容 |
| expireMinutes | int | 否 | 过期分钟数（默认1440=24小时） |

**响应数据（成功）：**
```json
{
  "success": true,
  "data": {
    "code": "3A7F21C8",
    "filename": "document.pdf",
    "fileSize": 1048576,
    "expiredAt": "2026-01-29T10:00:00Z"
  }
}
```

---

### 4. 分片上传（基于会话）

#### 4.1 创建临时上传会话

**接口：**
- **路径：** `POST /api/v1/temp/upload/session`
- **认证要求：** 基于IP
- **请求格式：** JSON

**请求参数：**
```json
{
  "filename": "largefile.zip",
  "fileSize": 104857600
}
```

**响应数据：**
```json
{
  "success": true,
  "data": {
    "uploadId": "uuid-字符串",
    "chunkSize": 5242880,
    "totalChunks": 20,
    "uploadedChunks": [],
    "expiredAt": "2026-01-29T10:00:00Z"
  }
}
```

#### 4.2 获取会话状态

**接口：**
- **路径：** `GET /api/v1/temp/upload/session/:uploadId`
- **认证要求：** 基于IP

**响应数据：**
```json
{
  "success": true,
  "data": {
    "uploadId": "uuid-字符串",
    "fileName": "largefile.zip",
    "fileSize": 104857600,
    "totalChunks": 20,
    "uploadedChunks": [0, 1, 2, 3],
    "status": "uploading",
    "expiredAt": "2026-01-29T10:00:00Z"
  }
}
```

#### 4.3 上传分片

**接口：**
- **路径：** `POST /api/v1/temp/upload/chunk`
- **认证要求：** 基于IP
- **请求格式：** `multipart/form-data`

**请求参数：**
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| uploadId | string | 是 | 会话ID |
| chunkIndex | int | 是 | 分片索引（从0开始） |
| file | File | 是 | 分片数据 |
| checksum | string | 否 | xxh3校验值 |

**响应数据：**
```json
{
  "success": true,
  "data": {
    "uploadedChunks": [0, 1],
    "remaining": 18
  }
}
```

#### 4.4 完成上传

**接口：**
- **路径：** `POST /api/v1/temp/upload/finalize`
- **认证要求：** 基于IP
- **请求格式：** JSON

**请求参数：**
```json
{
  "uploadId": "uuid-字符串"
}
```

**响应数据：**
```json
{
  "success": true,
  "data": {
    "code": "3A7F21C8",
    "filename": "largefile.zip",
    "fileSize": 104857600,
    "expiredAt": "2026-01-29T10:00:00Z"
  }
}
```

## 分片上传流程

```
客户端                              服务端
  |                                   |
  |-- POST /temp/upload/session ----->|
  |<-- uploadId, chunkSize -----------|
  |  创建会话                         |
  |                                   |
  |-- POST /temp/upload/chunk (0) --->|
  |<-- uploadedChunks: [0] ------------|
  |                                   |
  |-- POST /temp/upload/chunk (1) --->|
  |<-- uploadedChunks: [0,1] ---------|
  |  ... (可并发)                      |
  |                                   |
  |-- POST /temp/upload/finalize ---->|
  |<-- code, filename, fileSize ------|
  |  生成访问码                        |
```

## 配额管理

### 配额类型

#### 1. 全局配额

**配置项：**
- `storage.temp.quota.global` - 全局存储配额（所有临时文件）

#### 2. IP配额

**配置项：**
- `storage.temp.quota.per_ip` - 单个IP存储配额

### 默认配置

```yaml
storage:
  temp:
    enabled: true
    path: "./data/temp"
    quota:
      global: "10G"          # 全局总配额
      per_ip: "500M"         # 单IP配额
    default_expire_days: 7   # 默认过期天数
    delete_on_download: false
```

### 上传临时文件

```javascript
async function uploadTempFile(file, expireMinutes = 1440) {
  const formData = new FormData();
  formData.append('file', file);
  formData.append('expireMinutes', expireMinutes);

  const res = await fetch('/api/v1/temp/upload', {
    method: 'POST',
    body: formData
  });

  const { data } = await res.json();
  return data.code; // 返回访问码
}
```

### 分片上传

```javascript
class TempChunkedUploader {
  constructor(file) {
    this.file = file;
    this.chunkSize = 5 * 1024 * 1024; // 5MB
  }

  async upload() {
    // 1. 创建会话
    const sessionRes = await fetch('/api/v1/temp/upload/session', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        filename: this.file.name,
        fileSize: this.file.size
      })
    });
    const session = await sessionRes.json();

    // 2. 上传分片
    const totalChunks = Math.ceil(this.file.size / this.chunkSize);
    for (let i = 0; i < totalChunks; i++) {
      const start = i * this.chunkSize;
      const end = Math.min(start + this.chunkSize, this.file.size);
      const chunk = this.file.slice(start, end);

      const formData = new FormData();
      formData.append('uploadId', session.data.uploadId);
      formData.append('chunkIndex', i);
      formData.append('file', chunk);

      await fetch('/api/v1/temp/upload/chunk', {
        method: 'POST',
        body: formData
      });
    }

    // 3. 完成上传
    const finalizeRes = await fetch('/api/v1/temp/upload/finalize', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ uploadId: session.data.uploadId })
    });
    const result = await finalizeRes.json();
    return result.data.code;
  }
}
```

## 安全考虑

### 已实现措施

1. **IP识别**
   - 自动获取客户端真实IP
   - 支持代理场景下的IP获取

2. **配额控制**
   - IP级别文件数量限制
   - IP级别存储配额限制

3. **访问控制**
   - 只有文件上传者可以删除
   - 访问码随机生成（8位十六进制）

4. **过期机制**
   - 自动过期时间设置
   - 后台定时清理过期文件

### 建议改进

1. **下载频率限制** - 防止恶意访问
2. **IP黑名单** - 封禁滥用IP
3. **文件类型限制** - 白名单机制

## 错误处理

| 错误情况 | HTTP状态码 | 错误信息 |
|---------|-----------|---------|
| 超出IP文件数限制 | 400 | 超出IP文件数限制 |
| 超出IP存储配额 | 400 | 超出IP存储配额 |
| 文件不存在 | 404 | 文件不存在或已过期 |
| 无权删除 | 403 | 无权删除此文件 |
| 会话不存在 | 404 | 上传会话不存在 |
| 分片校验失败 | 400 | xxh3校验失败 |

## 与旧版临时文件模块的区别

| 特性 | 旧版 | 新版 |
|------|------|------|
| 认证方式 | 需要JWT登录 | 基于IP，无需登录 |
| 用户隔离 | UUID用户隔离 | IP隔离 |
| 存储方式 | 文件去重+引用计数 | 简单文件存储 |
| 上传方式 | 分片位图追踪 | 会话模式 |
| 配额控制 | 用户配额 | IP配额 |
