# 功能需求规格说明书 - 总结

## 项目概述

**项目名称：** 轻共享（Light Share）

**项目版本：** v3.0

**项目描述：**
轻共享是一个基于Go语言开发的轻量级文件共享系统，提供简单易用的文件分享功能。系统支持文件上传、下载、搜索、浏览、临时文件分享、私有存储等功能，并提供了Web界面和命令行接口。

**技术栈：**
- 后端：Go + Gin框架
- 前端：Vue 3 + **Naive UI** + Vite
- 实时通信：Server-Sent Events (SSE)
- 大文件上传：分片上传 + **xxh3**校验
- 认证：JWT (JSON Web Token)
- 配置：YAML
- 数据库：SQLite/MySQL/PostgreSQL
- 监控：Prometheus

**核心特性：**
- 跨平台支持（Windows/macOS/Linux）
- 文件浏览、预览、下载、上传
- 多根目录管理
- 文件配额控制
- 分片上传支持大文件（带断点续传）
- 实时文件搜索（SSE流式结果）
- 命令行搜索接口
- 临时文件分享（基于IP，无需登录）
- 私有存储（需要登录）
- 管理员后台
- 内置FTP服务器
- **内置WebDAV服务器（外部应用访问）**
- **API Key认证（外部集成）**
- **LDAP认证（企业目录）**
- **RBAC权限控制**
- **OpenAPI文档**

**认证策略：**
- 普通文件模块（浏览、下载、上传、搜索）：无需认证，公开访问
- 临时文件模块：基于客户端IP，无需登录
- 私有存储模块：需要JWT认证
- 管理功能：需要JWT + Admin角色

## 核心功能详解

### 1. 认证与授权

**功能概述：**
为私有存储和管理功能提供基于JWT的用户认证，支持用户注册和登录。

**认证范围：**
- 普通文件模块（浏览、下载、上传、搜索）：无需认证，公开访问
- 临时文件模块：基于客户端IP，无需认证
- 私有存储模块：需要JWT认证
- 管理功能：需要JWT + Admin角色

**主要特性：**
- 用户自行注册
- 用户名/密码登录（bcrypt密码哈希）
- JWT令牌生成和验证（HS256算法）
- 令牌自动刷新机制
- 用户UUID v4标识符

**关键接口：**
- `POST /api/v1/auth/register` - 用户注册
- `POST /api/v1/auth/login` - 用户登录
- `POST /api/v1/auth/refresh` - 令牌刷新
- `GET /api/v1/auth/user` - 获取用户信息

**详细文档：** [01-认证与授权模块.md](./01-认证与授权模块.md)

### 3. 文件搜索（无需认证）

**功能概述：**
提供跨多根目录的实时文件搜索功能，支持Web界面和命令行接口（CLI），使用Server-Sent Events（SSE）技术实现流式数据传输。所有接口公开访问，无需认证。

**主要特性：**
- 实时搜索结果推送（SSE）
- Web界面搜索 + CLI搜索
- 按文件名和扩展名搜索
- 并发搜索（多目录同时进行）
- 搜索取消支持
- 结果数量限制
- 不区分大小写

**关键接口：**
- `GET /api/v1/search/*query` - 搜索文件（Web界面）

**CLI接口：**
- `GET /api/v1/cli/search/*query` - CLI搜索（需JWT）

**搜索模式：**
- 文件名搜索：`report` → 匹配包含"report"的文件
- 扩展名过滤：`report.pdf` → 匹配PDF文件且文件名包含"report"

**技术特点：**
- 使用 `filepath.Walk` 递归遍历
- 每个根目录独立goroutine
- 结果通过channel汇总
- SSE实时推送结果

**详细文档：** [03-文件搜索模块.md](./03-文件搜索模块.md)

### 4. 文件上传（无需认证）

**功能概述：**
支持本地文件上传、从URL下载上传，并支持大文件分片上传和断点续传。所有接口公开访问，无需认证。

**主要特性：**
- 本地文件上传
- 从URL下载文件
- 分片上传（支持大文件）
- 断点续传
- **xxh3校验**（高性能哈希）
- 配额检查
- 文件类型验证
- 基于会话的上传管理

**关键接口：**
- `POST /api/v1/uploads/session` - 创建上传会话
- `GET /api/v1/uploads/session/:id` - 获取会话状态
- `POST /api/v1/uploads/session/:id/resume` - 续传
- `DELETE /api/v1/uploads/session/:id` - 取消会话
- `POST /api/v1/uploads/chunk` - 上传分片
- `POST /api/v1/uploads/finalize` - 完成分片上传
- `POST /api/v1/uploads/url` - 从URL上传

**分片上传流程：**
```
1. 创建会话: POST /uploads/session
2. 上传分片: POST /uploads/chunk (可并发)
3. 完成上传: POST /uploads/finalize
```

**详细文档：** [04-文件上传模块.md](./04-文件上传模块.md)

## 安全特性

### 已实现的安全措施

1. **认证保护**
   - JWT令牌认证（HS256算法）
   - 令牌过期机制（24小时）
   - 令牌自动刷新功能（提前6小时）
   - bcrypt密码哈希

2. **授权控制**
   - 基于角色的访问控制（admin/user）
   - Admin权限验证中间件

3. **路径安全**
   - 路径越权检查
   - 目录遍历防护
   - 文件类型过滤

4. **网络安全**
   - CORS跨域处理
   - 安全响应头设置
   - 速率限制（默认60/分）
   - 请求ID追踪

5. **临时文件安全**
   - 基于IP的配额控制
   - 过期自动清理

### 安全头设置

| 响应头 | 值 |
|--------|-----|
| X-Content-Type-Options | nosniff |
| X-Frame-Options | DENY |
| X-XSS-Protection | 1; mode=block |

## 性能特性

### 并发处理

- **文件搜索：** 多目录并发搜索（goroutine + channel）
- **文件上传：** 分片并发上传
- **会话清理：** 后台定时清理

### 流式传输

- **搜索结果：** SSE实时推送
- **文件下载：** 流式响应
- **大文件上传：** 分片上传

### 资源管理

- **内存：** 单次处理，不累积结果
- **磁盘：** 配额限制，定期清理
- **日志：** Zap结构化日志 + lumberjack轮转
