# 文件管理模块

## 模块概述

文件管理模块是系统的核心功能，负责文件和目录的浏览、查询、下载、重命名、移动等操作。该模块支持多根目录管理，提供灵活的文件访问控制，并包含文件配额管理和上传记录追踪功能。

---

## 功能列表

### 1. 浏览并列出目录

**功能描述：**
查看目录结构和内容，支持浏览根目录和子目录。

**接口：**
- **路径：** `GET /api/v1/files/list`
- **认证要求：** 需要

**请求参数：**
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| path | string | 否 | 要浏览的路径，留空则返回根目录列表 |

**请求示例：**
```
GET /api/v1/files/list
```
```
GET /api/v1/files/list?path=documents/images
```

**响应数据：**
```json
{
  "success": true,
  "message": "",
  "data": [
    {
      "name": "documents",
      "type": "directory",
      "path": "documents",
      "modifiedTime": "2026-01-15T10:30:00Z",
      "size": 0,
      "quota": 10737418240,
      "used": 5242880
    },
    {
      "name": "report.pdf",
      "type": "file",
      "path": "documents/report.pdf",
      "modifiedTime": "2026-01-20T14:45:00Z",
      "size": 1048576
    }
  ]
}
```

**字段说明：**
- `name`: 文件或目录名称
- `type`: 类型，值为 `directory` 或 `file`
- `path`: 相对路径
- `modifiedTime`: 修改时间（RFC3339格式）
- `size`: 文件大小（字节）
- `quota`: 配额限制（仅根目录）
- `used`: 已使用空间（仅根目录）
- `downloadCount`: 该公共文件的累计下载次数（来自索引记录，默认 0）。程序升级/每次启动时，会从下载记录（`operation_records` 中 `action` 为 `download`/`download-by-hash` 的记录）统计各文件的次数一次性回写，幂等（仅回填仍为 0 的记录），之后由实时下载累加
- `canManage`: 当前请求者是否有权管理该文件（管理员，或上传者IP一致时可管理）

**管理权限模型：**
- 公共文件（覆盖上传、重命名、移动、删除）的管理权限遵循以下规则：
  - **管理员**始终拥有全部管理权限；
  - **上传者本人**（当前请求IP与该文件在索引表中的 `uploaderIp` 一致）拥有管理权限；
  - 其余用户无管理权限（服务端会返回 403 拒绝操作）。
- 列表接口对每个条目返回 `canManage` 字段，前端据此控制"重命名/删除"操作按钮的显隐。

**路径格式：**
- 根目录浏览：`path` 为空或省略
- 子目录浏览：`path=rootName/subPath` 格式

**自动过滤规则：**
- 隐藏以`.`开头且以`.bitmap`或`.uploading`结尾的临时文件
- 过滤不允许的文件类型（根据配置）

**空目录处理：**
- 目录为空时返回空数组 `[]`（success=true）
- 目录在文件系统上真实存在但无索引记录时，仍返回空数组而非报错

**错误情况：**
- 路径格式错误
- 目录不存在（文件系统与索引均不存在）
- 超出访问范围

### 3. 下载文件

**功能描述：**
下载服务器上的文件，支持预览模式和直接下载模式。

**接口：**
- **路径：** `GET /download/*path`（兼容旧路径：`GET /api/v1/download/*path`）
- **认证要求：** 需要

**请求参数：**
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| preview | boolean | 否 | 是否预览模式，默认false |
| path | string | 是 | 文件路径（URL路径的一部分） |

**请求示例：**
```
# 直接下载
GET /download/documents/report.pdf

# 预览文件（浏览器内打开）
GET /download/documents/image.png?preview=true
```

**响应行为：**

**预览模式（preview=true）：**
- 不设置`Content-Disposition`头
- 浏览器尝试直接显示文件内容
- 适用于图片、PDF等可直接显示的文件

**下载模式（preview=false或省略）：**
- 设置`Content-Disposition: attachment; filename=xxx`
- 浏览器将文件下载到本地

**下载次数统计：**
- 公共文件每次真实下载（`preview` 非 `true` 的 GET 请求），会将该文件在索引记录表中的 `download_count` 累加 1
- 预览请求（`preview=true`）不计入下载次数
- 下载次数会展示在公共文件列表中，并可作为排序依据

**支持的预览类型：**
- 图像文件：JPG、PNG、GIF、SVG等
- 文本文件：TXT、MD等
- PDF文档

**安全验证：**
- 验证路径格式（根目录/子路径）
- 验证根目录是否存在
- 验证目标路径是否越权

**错误情况：**
- 路径格式不正确：`{"success": false, "message": "路径格式错误"}`
- 目录不存在：`{"success": false, "message": "指定的目录不存在"}`
- 文件不存在：`{"success": false, "message": "指定的文件不存在"}`
- 路径越权：`{"success": false, "message": "路径越权"}`

### 4. 重命名文件

**功能描述：**
重命名文件或目录。

**接口：**
- **路径：** `POST /api/v1/files/rename`
- **认证要求：** 需要
- **权限：** 文件上传者IP一致或管理员

**请求格式：** JSON（兼容 `{ oldPath, newName }` 与 `{ path, newName }`）

**请求参数：**
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| oldPath | string | 是 | 当前文件完整路径（rootName/相对路径） |
| newName | string | 是 | 新文件名 |

**请求示例：**
```json
{
  "oldPath": "documents/oldname.txt",
  "newName": "newname.txt"
}
```

**响应数据：**
```json
{
  "success": true,
  "message": "重命名成功",
  "data": null
}
```

**验证规则：**
- 目标文件名不能已存在
- 上传者IP与文件 `uploaderIp` 不一致（且非管理员）时返回 403 拒绝操作

### 5. 移动文件

**功能描述：**
将文件移动到另一个目录。

**接口：**
- **路径：** `POST /api/v1/files/move`
- **认证要求：** 需要
- **权限：** 文件上传者IP一致或管理员

**请求格式：** JSON

**请求参数：**
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| oldPath | string | 是 | 源文件完整路径（rootName/相对路径） |
| newPath | string | 是 | 目标完整路径（rootName/相对路径） |

**请求示例：**
```json
{
  "oldPath": "documents/document.pdf",
  "newPath": "documents/final/document.pdf"
}
```

**响应数据：**
```json
{
  "success": true,
  "message": "移动成功",
  "data": null
}
```

**验证规则：**
- 源文件必须存在
- 目标目录必须存在
- 不能移动到同一个目录
- 上传者IP与文件 `uploaderIp` 不一致（且非管理员）时返回 403 拒绝操作

### 6. 删除文件

**功能描述：**
删除文件或目录（支持删除目录及其所有内容）。

**接口：**
- **路径：** `DELETE /api/v1/files/delete`
- **认证要求：** 需要
- **权限：** 文件上传者IP一致或管理员

**请求参数：**
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| path | string | 是 | 待删除文件的完整路径（rootName/相对路径），需 URL 编码 |

**请求示例：**
```
DELETE /api/v1/files/delete?path=documents/report.pdf
```

**响应数据：**
```json
{
  "success": true,
  "message": "删除成功",
  "data": null
}
```

**行为说明：**
- 删除目录时，会级联清理目录下所有文件的索引记录
- 删除成功后同步硬删除索引记录及相关索引数据
- 上传者IP与文件 `uploaderIp` 不一致（且非管理员）时返回 403 拒绝操作

### 7. 查看最近上传

**功能描述：**
查看最近上传的文件记录，便于追踪文件上传活动。

**接口：**
- **路径：** `GET /api/v1/files/recent`
- **认证要求：** 需要

**请求参数：**
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| count | int | 否 | 返回记录数，默认10，最大100 |

**请求示例：**
```
GET /api/v1/files/recent
```
```
GET /api/v1/files/recent?count=5
```

**响应数据：**
```json
{
  "success": true,
  "message": "",
  "data": [
    {
      "ipAddress": "192.168.1.100",
      "uploadTime": "2026-01-28T10:30:00Z",
      "filename": "presentation.pdf",
      "filePath": "/files/documents/presentation.pdf"
    },
    {
      "ipAddress": "192.168.1.101",
      "uploadTime": "2026-01-28T09:15:00Z",
      "filename": "image.png",
      "filePath": "/files/images/image.png"
    }
  ]
}
```

**记录限制：**
- 系统最多保留最近100条上传记录
- 新记录添加到列表开头
- 自动清理旧记录

**字段说明：**
- `ipAddress`: 上传者IP地址
- `uploadTime`: 上传时间
- `filename`: 文件名
- `filePath`: 文件完整路径

## 目录结构管理

### 多根目录支持

系统支持配置多个根目录，每个根目录可独立设置配额。

**配置示例：**
```yaml
storage:
  public:
    root_dirs:
      - path: "/data/files"
        quota: 10737418240  # 10GB
      - path: "/data/documents"
        quota: 5368709120   # 5GB
      - path: "/data/images"
        quota: 2147483648   # 2GB
```

**目录命名：**
- 系统自动为每个根目录分配名称
- 名称基于目录路径生成

### 路径格式规范

**格式：** `rootName/subPath`

**示例：**
- 浏览根目录：`/files/list`
- 浏览子目录：`/files/list?path=documents/2024`
- 访问文件：`/documents/report.pdf`

### 路径越权保护

系统实现路径遍历攻击防护：

**检测机制：**
- 验证目标路径是否在根目录范围内
- 防止`../`路径穿越攻击
- 符号链接安全检查

**违规处理：**
```json
{
  "success": false,
  "message": "路径越权"
}
```

**配置：**

```yaml
storage:
```

## 配额管理

### 目录配额

每个根目录可设置独立的存储配额。

**获取配额信息：**
浏览根目录时返回配额数据：
```json
{
  "name": "files",
  "type": "directory",
  "quota": 10737418240,
  "used": 5242880,
  "quotaPercent": 48.8
}
```

**计算方式：**
- `quota`: 配额上限（0表示无限制）
- `used`: 已使用字节数
- 配额百分比 = (used / quota) * 100

### 上传前检查

文件上传前验证剩余空间是否充足。

---

## 临时文件过滤

系统自动过滤上传过程中产生的临时文件：

**过滤规则：**
- 文件名以`.`开头
- 以`.bitmap`或`.uploading`结尾

**示例（被过滤）：**
- `.test.pdf.uploading`
- `.temp-file.docx.bitmap`
- `.chunk_001.dat.uploading`

**原因：**
这些是分片上传过程中使用的临时文件，不应向用户展示。

```json

  "name": "string",           // 文件名

  "path": "string",           // 相对路径
```

```json
{
  "ipAddress": "string",      // IP地址

}
```

### ListDirectoriesRequest
```json
{
  "path": "string"            // 查询路径
}
```

### GetRecentUploadsRequest
```json
{
  "count": 0                  // 记录数量
}
```

## 错误处理

| 错误代码 | 错误信息 | 原因 |
|---------|---------|------|
| 400 | 路径格式错误 | 路径不符合根目录/子路径格式 |
| 400 | 指定的目录不存在 | 根目录名称未配置 |
| 400 | 指定的文件不存在 | 目标路径不存在或不是文件 |
| 403 | 路径越权 | 试图访问根目录范围之外的路径 |
| 500 | 获取文件信息失败 | 文件系统错误 |

## 前端交互

### 文件列表展示

**功能：**
- 表格形式展示文件和目录
- 支持按名称、类型、大小、修改时间排序
- 界面排序：公共文件列表（含搜索结果）支持点击表头按**路径（文件名）**、**修改时间**、**下载次数**排序，目录始终排在文件前，仅影响当前界面展示，不涉及后台
- 显示文件类型图标
- 显示每个公共文件的下载次数（`downloadCount`）
- 点击行查看详情或下载
- 操作列（el-dropdown 拆分按钮，仅文件）：默认主按钮为「依赖」，点击打开该文件的依赖树；下拉菜单含**移动 / 重命名 / 删除**，仅对 `canManage` 为 true 的文件（管理员，或上传者IP一致）显示下拉管理菜单，其余文件仅保留「依赖」入口
- 版本标记：自动识别同一程序的最新版本（文件名仅版本号/数字段差异视为同一程序，如 `app_v1.0.exe`/`app_v2.0.exe`、`report.pdf`/`report(1).pdf`），最新版本文件名加粗并显示"最新"标签；无相似文件则不标记。分析范围仅限当前目录，搜索模式下不标记

**面包屑导航：**
- 显示当前路径
- 支持快速跳转到父目录

**操作菜单：**
- 重命名
- 移动
- 下载
- 删除（支持勾选多行后批量删除，支持删除目录及其所有内容）
