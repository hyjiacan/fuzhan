## 3. 测试类型

### 3.1 单元测试

- 独立函数测试
- 哈希算法一致性验证
- 配置解析测试

### 3.2 集成测试

- HTTP API 端点测试
- 数据库操作测试
- 路由配置测试

### 3.3 E2E 测试

基于业务功能的端到端测试，使用 Playwright 框架，覆盖用户认证、文件操作、管理功能等核心业务流程。

## 4. 运行测试

```bash
# 后端测试
cd server && go test ./...

# 前端测试
cd ui && yarn test

# E2E 测试（需要开发服务器运行）
cd ui && yarn playwright test
```

## 5. 覆盖率目标

- 核心业务逻辑：> 70%
- API 端点：> 80%
- 工具函数：> 90%

## 7. 错误监控

E2E 测试使用 `e2e/setup.ts` 捕获以下错误：

- **控制台错误**: 监听 `console.error` 事件
- **网络请求失败**: 监听 `requestfailed` 事件

测试完成后会输出捕获的错误信息，便于分析应用问题。
